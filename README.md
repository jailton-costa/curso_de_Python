# Curso de Python (Python 3.13) | Senai Florianópolis

Repositório de arquivos de desenvolvimento de programação em Python no Senai Florianópolis.


## 📌 Objetivo

Aprender programação em Python de forma prática, com foco em desenvolvimento real.


## ⚙ Estrutura do Repositório

- `atividades em sala/`: Exercícios práticos realizados durante as aulas.

- `exercícios para casa/`: Tarefas para reforçar o aprendizado.

- `explicações em aulas/`: Materiais e slides utilizados nas aulas.



## ❕ Instalar as dependências do projeto

Como o código usa várias bibliotecas, você tem que instalar esses comando abaixo no terminal:

```bash
pip install pandas numpy matplotlib scikit-learn seaborn
```

Se der erro de permissão, use:
```bash
python -m pip install pandas numpy matplotlib scikit-learn seaborn
```
